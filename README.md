## 🌟 Overview

**Alpha Financial Services** is a modern, high-performance web platform designed to streamline institutional loan lifecycle operations, capital origination, delinquency tracking, and credit risk scoring. Tailored out-of-the-box for **Ugandan Shillings (UGX)** financial markets (with full multi-currency configurability), it empowers credit officers and administrators with real-time portfolio exposure metrics and visual analytics.

Designed with an **institutional glassmorphism UI aesthetic**, responsive micro-animations, interactive dynamic charts, and an automated **Credit Reference Bureau (CRB) risk scoring matrix**.

---

## 🔥 Key System Capabilities

- **📊 Portfolio Executive Dashboard**: Real-time KPI tracking for Gross Portfolio Capital, Amortization Collections, Active Credit Lines, and NPA (Non-Performing Assets) exposure.
- **📈 Dynamic Chart.js Analytics**: Interactive doughnut asset allocation mix charts and monthly capital disbursal vs. collection yield breakdown graphs.
- **📜 Credit Origination & Amortization Engine**: Built-in schedule calculator for flat-rate and reducing-balance facilities with automatic installment tracking.
- **🛡️ CRB Risk Matrix Engine**: Automated credit scoring algorithm evaluating Debt-To-Income (DTI) ratios, income brackets, and delinquency history (Ratings from `AAA` Prime to `D` Subprime).
- **📁 Data Backup & Cloud REST API Simulator**: Instant CSV export for borrower registries & loan reports, full JSON database backup/restore capability, and asynchronous cloud sync simulation.
- **🖨️ Institutional Audit Print Streams**: Clean CSS `@media print` rules for generating instant loan statements and official receipts.

---

## 🛠️ Technology Stack

- **Core Engine**: Vanilla JavaScript (ES6+), Modern HTML5
- **Styling & Aesthetics**: Custom CSS3 System, CSS Grid & Flexbox, Glassmorphic Backdrop Blurs, HSL Tailored Color Tokens
- **Iconography & Visuals**: Remixicon (v3.5.0)
- **Data Visualizations**: Chart.js (CDN integration)
- **Data Storage**: Browser Local Storage Engine with local JSON database import/export handlers
